# 앱 로고 (tool logos)

각 도구의 공식 로고를 여기에 둔다. 사이트 브랜드 자산(나침반)은 `assets/brand/`에 별도로 있다.

## 사용 방법
- `data/tools.json`(또는 `tool-enrichment.json`)의 도구에 `"logo_url": "assets/logos/<id>.png"` 지정
- `logo_url`이 있으면 카드·상세 표지에서 그 이미지를 우선 사용한다 (`assets/app.js`)
- 없으면 도구 URL 기반 Google S2 favicon → 실패 시 분야별 Lucide 아이콘으로 대체

## 로고 찾는 순서
1. 서비스 공식 사이트의 로고 이미지
2. **공식 사이트에서 찾기 어려우면 Google Play 스토어 웹**에서 앱 아이콘을 사용한다
   - 앱 페이지의 아이콘 이미지 주소(`play-lh.googleusercontent.com/...`)를 그대로 내려받는다
   - `=w480-h960-rw` 형태의 크기 파라미터가 붙어 있으며 대개 WebP로 내려온다 → 확장자를 실제 포맷에 맞춘다
3. 그래도 없으면 `logo_url`을 비워 둔다 (도메인 파비콘 → 분야 아이콘으로 자동 대체)

## 규칙
- 파일명은 도구 `id`와 일치 (예: `dahandin.png`)
- 확장자는 **실제 파일 포맷과 일치**시킨다. Play 스토어 이미지는 보통 `.webp`
  (`file` 명령으로 확인. 확장자와 실제 포맷이 다르면 서버 MIME이 어긋난다)
- 정사각형 PNG 권장(투명 배경 또는 원본 그대로), 표시 크기는 CSS가 처리(48px 카드 마크)
- **저작권**: 공식 로고는 각 서비스 소유. 사용 조건·출처를 확인한 뒤 추가할 것
- 외부 favicon 서비스 의존을 줄이려면 자주 노출되는 도구부터 로컬 로고로 교체
