- 상세 카드를 화면 높이 안에 고정하고 상단 표지·도구명·수업 제안을 유지한 채 `대상 학령` 이후 정보만 내부 스크롤하도록 바꿨다.
- 상단의 중복 `필터 초기화` 버튼을 제거하고, 랜딩 복귀와 빈 결과 조건 해제의 동작을 분리했다.
- 분류·비교·링크 복사·필터 펼치기에 상태별 Lucide 아이콘을 적용했다.

- 데이터 검증 범위를 택소노미 배열·검증일·출처 중복·조사 대기열까지 확장하고, 정기 재검증 점검 명령과 배포·운영 문서를 추가했다.
- 추가 교육앱 후보로 PhET·GeoGebra·Book Creator·Edpuzzle·Plickers·Genially 등을 검토하고, `수학·과학·시뮬레이션` 신규 분류를 후속 결정으로 기록했다.
