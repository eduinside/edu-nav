## 3. 사용자 확정 결정

### 콘텐츠·운영

- 국내 도입 가능성과 교사 실사용을 우선한다.
- 글로벌 도구도 국내 대체재가 부족하거나 교사 활용성이 높으면 포함할 수 있다.
- 연령, 학생 계정, 개인정보, 요금과 공식 근거를 핵심 판단 정보로 유지한다.
- S2B 공개목록에서 찾지 못한 경우 `미입점`으로 단정하지 않고 `공개목록에서 미확인`으로 표현한다.
- 데이터는 당분간 수동 JSON으로 관리한다.
- 즐겨찾기·로그인·댓글·사용자 평가는 수요 확인 전까지 보류한다.

### 디자인

- 사용자가 제안안 중 1번인 **감각적이고 단정한 ‘조용한 도서관’ 방향**을 선택했다.
- 글꼴은 **Pretendard**를 선호한다.
- 한 화면의 텍스트 밀도를 낮춘다.
- 첫 화면은 사이트 소개와 분류 선택 중심으로 구성한다.
- 도구 목록은 분류 선택 또는 검색을 시작한 뒤에만 표시한다.
- 로고를 누르면 항상 랜딩으로 돌아간다.
- Lucide 아이콘을 일관되게 사용한다.
- 카드와 상세 화면은 교사가 빠르게 판단할 수 있는 정보 위계를 우선한다.

### 배포·향후 기능

- Cloudflare Pages 연결은 보류한다.
- 정본 도메인 결정도 보류한다.
- 추후 자연어로 에듀테크를 제안하는 간단한 챗봇형 기능을 구현한다.
- 챗봇은 검증된 현재 데이터 안에서만 후보를 고르고, AI는 설명 역할만 맡기는 방향이다.

- Wakelet은 최신 약관상 학생·학교 단위 사용을 Education Enterprise로 보는 조건이 있어 우선 후보에서 제외했다.

## 11. AI 추천 도우미 계획

상세 계획은 `docs/EDZIP-INTEGRATION-PLAN.md`의 `후속 확장 — AI 에듀테크 추천 도우미`를 따른다.

### 목표

교사가 학년·교과·수업 목표·학생 직접 사용 여부를 자연어로 입력하면 현재 검증 데이터 안에서 2~3개 도구를 이유와 함께 제안한다.

### 구현 단계

1. **P5-1 규칙 추천**
   - 기존 JSON과 필터 규칙만 사용
   - 학년, 교과, 수업 단계, 계정, 한국어 조건으로 3개 후보 제시
   - AI 없이 동작

2. **P5-2 AI 설명**
   - 규칙으로 확정한 후보만 서버 측 AI에 전달
   - 추천 사유, 주의점, 필요한 확인 질문만 생성
   - 화면의 연령·가격·출처는 원본 JSON 값만 사용

3. **P5-3 안전장치**
   - 학생 개인정보 입력 금지
   - 대화 저장 기본 비활성화
   - 모델 장애 시 규칙 추천으로 자동 전환
   - 현재 데이터에 없는 도구·가격·연령 생성 금지

4. **P5-4 교사 검증**
   - 교사 5명 이상
   - 추천 적합성, 안전 누락, 질문 수 기록

### 기술 경계

- 정적 카탈로그와 추천 로직을 분리한다.
- API 키를 `assets/app.js` 또는 클라이언트 환경 변수에 넣지 않는다.
- AI 호출은 추후 Cloudflare Worker 같은 서버 측 계층에서만 한다.
- 모델 응답의 도구 ID가 현재 공개 데이터에 실제 존재하는지 화면에서 검증한다.

## 13. 보류·금지 사항

- 사용자 요청 없이 Cloudflare Pages에 배포하지 않는다.
- 정본 도메인을 임의로 정하지 않는다.
- 이전 ChatGPT Sites 프로젝트 ID를 현재 프로젝트에 연결하지 않는다.
- 학생 개인정보를 수집하거나 AI에 전송하지 않는다.
- 출처가 없는 연령·가격·한국어 지원을 추정하여 공개하지 않는다.
- 공식 로고 파일을 라이선스 확인 없이 대량 복제하지 않는다.
- 기존 데이터 80개를 이유 없이 재작성하거나 ID를 변경하지 않는다.
