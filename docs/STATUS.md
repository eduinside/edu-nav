- `data/*.json`을 fetch하므로 `file://` 직접 열기 불가 → 로컬은 `node scripts/serve.mjs`
- 데이터는 수기 관리(JSON). 규모 커지면 관리 도구/검증 스크립트 필요
- Pretendard·Lucide·앱 파비콘이 외부 CDN/서비스에 의존하므로 학교망·오프라인 대응 시 로컬화 필요
- 실제 모바일 기기와 스크린리더 실기기 테스트는 남아 있음
