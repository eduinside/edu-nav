# AI 학습도구 큐레이션 사이트 — 기획 문서

초·중·고 교사가 수업에서 활용할 수 있는 **AI 기반 학습도구**를 분야별로 정리·분류해
필터·검색 가능한 형태로 제공하는 정적 홈페이지.

- **대상 사용자**: 초·중·고 교사 (제작자: 대구광역시교육청 교사)
- **레퍼런스 기준**: edzip(에듀집), 에듀테크몰 — 국내에서 실제 많이 활용되는 도구 목록
- **정본 스택(예정)**: Cloudflare Pages (정적). 무료 티어 유지가 제약조건.
- **상태**: 핵심 프로토타입 완료 · 콘텐츠 확장·배포 보류 — 공개 도구 80개, 심층 보강 16개, 공식 출처 47건 (2026-07-24)

---

## 확정된 방향 (사용자 결정)

| 항목 | 결정 | 의미 |
|---|---|---|
| **수집 범위** | 국내 도입 도구 우선 | 에듀테크몰·에듀집 등재 또는 한국어 지원/국내 활용도 높은 도구 중심. `한국어 지원`·`국내 도입`은 태그로도 유지. |
| **정보 깊이** | 표준 프로필 | 도구당 이름·분류·대상·교과·요금·연령제한·한줄설명·공식링크 + 수업활용 한 줄. |
| **1차 리서치 분야** | ① 코스웨어·LMS·평가 ② AI 튜터·챗봇·발표자료 | 나머지 분야(글쓰기·이미지·영상·음악·코딩 등)는 2차 확장. |
| **디자인** | 조용한 도서관형 랜딩 우선 UI + Pretendard | 분야 선택·검색 후에만 목록을 표시하고 한 화면의 텍스트 밀도를 낮춤. |
| **배포** | Cloudflare Pages·정본 도메인 보류 | 사용자가 요청할 때 연결. 현재는 로컬 정적 정본 유지. |
| **향후 AI** | 규칙 추천 우선, 서버 측 AI 설명 후속 | 검증 데이터 밖의 도구·가격·연령을 생성하지 않도록 경계. |

## 분류 체계 (다축 태깅)

한 도구를 단일 카테고리에 가두지 않고 여러 축으로 태깅한다 → 정적 사이트에서 자유로운 필터·검색.

| 축 | 값 |
|---|---|
| **① 기능 분야** (주 카테고리) | 글쓰기·작문 / 이미지·그림 / 영상 / 음악·오디오 / 프레젠테이션·디자인 / 코스웨어·LMS / 평가·퀴즈·피드백 / 코딩·SW교육 / 번역·외국어 / AI 튜터·챗봇 / 리서치·자료정리 / 교사 업무자동화 |
| **② 대상 학령** | 초등(저/고) · 중 · 고 · 성인/교사 |
| **③ 교과 연계** | 국어·영어·수학·과학·사회·미술·음악·정보·실과·창체·범교과 |
| **④ 활용 주체** | 학생 직접 사용 / 교사 제작·준비용 |
| **⑤ 요금** | 완전무료 / 교육용 무료(에듀 플랜) / 부분무료(프리미엄) / 유료 |
| **⑥ 접근성·안전** | 로그인 필요여부 · **연령제한(13/14/18+)** · 한국어 지원 · 개인정보 수집수준 · 교내 도입 적합성 |
| **⑦ 도입 형태** | 웹 / 설치형 / 브라우저 확장 / 앱 · 계정발급 방식 |

> ⑥ 접근성·안전 축은 국내 K-12 특화 핵심 정보. 다수 글로벌 AI 도구가 만 13/18세 미만 사용 제한이 있어,
> "우리 반 학생이 직접 써도 되는가"를 교사가 즉시 판단할 수 있어야 한다.

### 등재 기준 (Inclusion criteria)
- edzip·에듀테크몰 등재 또는 국내 교사 커뮤니티에서 실사용 사례가 확인되는 도구
- 한국어 미지원이라도 국내 활용도가 높으면 등재하되 `한국어 지원: 아니오`로 명시
- 서비스 종료/장기 미업데이트 도구는 제외
- 유료 도구도 등재 가능 (요금 축으로 명시) — 무료 티어 제약은 **우리 사이트 인프라**에 대한 것이지 소개 도구에 대한 것이 아님

## 로드맵 (4단계)

1. **기준 수립** ✅ 완료. 택소노미 확정 + 본 문서 + 데이터 스키마.
2. **리서치** ✅ 1차 통합 완료. 공개 80개, 심층 보강 16개, 공식 출처 47건, 조사 대기열 7개.
3. **데이터 구조 + UI 설계** ✅ 완료. 랜딩·필터·앱 로고 카드·상세·비교·공유 구조 확정.
4. **정적 사이트 구축** ✅ 로컬 프로토타입 완료(`index.html` + `assets/`). Cloudflare Pages는 사용자 결정으로 보류.
5. **후속 확장** 🔄 수학·과학 시뮬레이션 분야와 추가 교육앱 조사, 규칙 기반 AI 추천 도우미 검토.

## 프로토타입 실행
```
node scripts/serve.mjs   # http://localhost:5173 (data/*.json fetch 때문에 file:// 불가)
```
- `index.html` · `assets/styles.css` · `assets/app.js` — 무빌드 순수 정적. `data/tools.json`+`taxonomy.json`을 fetch해 렌더.
- 기능: 랜딩 분야 선택, 텍스트 검색, 다축 필터, 앱 로고 카드, 카드 전체 상세 열기, 수업 제안, 공유 딥링크, 최대 4개 비교. 연령제한은 색상으로 안전도 강조.
- 배포: 정적 파일 그대로 Cloudflare Pages 업로드(빌드 명령 불필요).
